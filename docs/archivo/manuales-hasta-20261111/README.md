# Archivo de manuales anteriores

El 11 de noviembre de 2026 se trasladaron aquí los **58 archivos** (incluido un archivo de metadatos Finder) que existían en `docs/manuales`, incluidos PDF, DOC, DOCX, fuentes, paquetes, matrices y XML de las entregas anteriores. No se borró ninguno y se comprobó su integridad con SHA-256.

- `20261106/`: los cinco manuales por perfil anteriores y sus materiales.
- `teams-20261110/`: manual anterior de Teams.
- `produccion-20261110/`: manual anterior del pase a producción.
- Los archivos de la raíz incluyen las guías anteriores de usuarios y despliegue.
- `ARCHIVO_INTEGRIDAD.json`: ruta original relativa, tamaño y SHA-256 de cada archivo trasladado.
- `INDICE_DOCUMENTACION_ANTERIOR.md`: copia del índice anterior tal como estaba; sus enlaces conservan las rutas previas al traslado.
- `generadores/`: copia de las herramientas anteriores para consulta. Las herramientas operativas siguen en `scripts/` del repositorio; las históricas apuntan a este archivo.

Estos documentos se conservan como referencia histórica. Para el uso actual de PRE, abrir los [cuatro manuales nuevos](../../manuales/20261111/README.md).

Limpieza del 12/11/2026: se retiró el archivo `.DS_Store` de Finder. Los 57 archivos documentales y de apoyo permanecen intactos. `ARCHIVO_INTEGRIDAD.json` verifica esos 57; `ARCHIVO_INTEGRIDAD_ORIGINAL.json` conserva el inventario anterior y `LIMPIEZA_METADATOS_20261112.json` registra la retirada.
